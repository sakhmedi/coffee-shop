# DALA COFFEE — правила проекта

Лендинг кофейни в Астане. Vite + Tailwind v4 (`@tailwindcss/vite`), ванильный JS,
модули ES, бэкенда нет. Запуск: `npm run dev` (порт 5173), сборка: `npm run build`.

Правила ниже уже действуют в коде. Это не пожелания на будущее — новая секция,
написанная мимо них, будет выбиваться из уже сделанного. Если правило мешает,
сначала обсуждаем, потом меняем — молча обойти нельзя.

## Структура

```
index.html          вся разметка страницы + <template> для JS
src/styles.css      дизайн-система: @theme static, base-слой, @utility
src/i18n.js         t(), translateTree(), applyLang(), onLangChange()
src/cart.js         состояние корзины + localStorage
src/main.js         шапка, переключатель языка, мобильное меню, сборка инитов
src/data/menu.js    напитки, категории, formatPrice()
src/data/locale.js  все строки интерфейса: ru / kk
src/ui/menu.js      секция «Меню»: фильтры и карточки
src/ui/weekly.js    промо-блок «Напиток недели»
src/ui/cart-panel.js счётчик в шапке и модальная панель корзины
src/ui/toast.js     showToast()
```

Разметка секций — в `index.html`, повторяющиеся элементы — в `<template>`
внизу файла, JS клонирует шаблон и заполняет по `data-*`. HTML строками
в JS не собираем.

## Цвет

Палитра закрыта: в `@theme static` стоит `--color-*: initial`, дефолтный
namespace Tailwind сброшен. Утилит вроде `bg-blue-500` в проекте физически
не существует. Доступны только:

| токен | назначение |
| --- | --- |
| `--color-espresso` `#2b1a12` | текст, тёмные секции, главные кнопки |
| `--color-milk` `#f7f2ec` | фон страницы |
| `--color-caramel` `#a9714b` | крупные цены (от 24px), бордеры, точки-маркеры, заливки под ТЁМНЫМ текстом |
| `--color-cocoa` `#8c5a38` | мелкий текст и ссылки на светлом, заливки под белым текстом |
| `--color-blush` `#f6e3de` | фон акцентных блоков и промо |
| `--color-stone` `#8a7466` | второстепенный текст, бордеры, разделители |
| `--color-white` `#ffffff` | белый текст на тёмной заливке |
| `--color-alert` `#9e3b2b` | только ошибки валидации и деструктивные действия |

Плюс служебные `transparent` / `current` / `inherit`.

Холодных цветов на сайте нет. Синего, серо-синего, зелёного не появляется
даже «на один бейдж» — гамма тёплая целиком.

**Сплошная заливка под белым текстом — только `--espresso` или `--cocoa`,
никогда `--caramel`.** Белое на caramel даёт 4.08:1 при норме 4.5:1;
на cocoa — 5.78:1. Caramel остаётся цветом крупных цен, бордеров и точек.

Кнопка «Отправить» (как и все главные CTA: «В корзину», «Смотреть меню»,
«Все напитки») — заливка `--espresso`, текст `--milk`, hover `--cocoa`.

`--blush` — максимум в двух секциях на страницу. Сейчас занято: градиент
под фото в hero и плашка «Напиток недели». Третья секция на blush превращает
акцент в фон. Точечный `hover:bg-blush` на кнопках сюда не считается.

`--alert` — только ошибки валидации и деструктивные действия («Очистить
корзину»). Не для акцентов, бейджей, скидок и «важных» плашек: если он
появляется там, где ничего не сломано, он перестаёт работать там, где сломано.
Контраст на milk — 6.1:1, на espresso — 2.5:1, **поэтому в тёмных секциях
ошибку показываем текстом на светлой подложке, а не alert по тёмному**.
Деструктивная кнопка берёт alert бордером и текстом, не сплошной заливкой:
«Очистить» не должно быть самой заметной кнопкой в панели.

Цвет — никогда не единственный признак ошибки: рядом всегда текст сообщения,
его контейнер — `aria-live="polite"`, а на самом поле `aria-invalid`
и `aria-describedby`.

## Типографика

Два шрифта: `--font-display` (Unbounded) для заголовков, `--font-sans` (Inter)
для текста. Оба покрывают кириллицу и казахские ә ғ қ ң ө ұ ү һ і.

Шкала кеглей закрыта (`--text-*: initial`), ровно 7 ступеней:

`caption` 12 · `small` 14 · `body` 16 · `lead` 20 · `h3` 28 · `h2` 40 · `h1` 64

Промежуточных значений нет, произвольных `text-[22px]` — тоже.
Интерлиньяж: 1.6 для текста, 1.2 для заголовков — зашит в токены.

Радиусы: `xs` 4 · `sm` 8 · `md` 14 · `lg` 24 · `pill` 999 — у каждого своё
назначение, чтобы блоки не стали одним и тем же скруглённым прямоугольником.

Утилиты проекта: `shell` (контейнер 1200px), `measure` (строка ≤ 70ch),
`no-scrollbar`, `tnum` (табличные цифры для цен), `skip-link`.

## Тексты и язык

Все строки — в `src/data/locale.js`, в разметку попадают через атрибуты:

- `data-i18n="nav.menu"` — текст элемента;
- `data-i18n-aria-label="a11y.openCart"` — атрибут `aria-label`;
- любой `data-i18n-<имя>` кладёт перевод в атрибут `<имя>`
  (`data-i18n-content`, `data-i18n-alt` и т.д.).

Захардкоженных строк в HTML и JS нет. Русский текст, который виден в разметке, —
это фолбэк до первого `translateTree()`, а не источник правды: ключ обязателен.
Названия и описания напитков — исключение, они живут в `data/menu.js`
как `{ ru, kk }`.

**Публичная `t(key, vars)` языка не принимает.** Третий параметр убран
намеренно: пока он был, вызов `t('nav.menu', lang)` выглядел рабочим,
но молча возвращал строку без подстановки. Язык знает только внутренняя
`translate(key, vars, lang)`, ей пользуется `translateTree`.

Смена языка не перезагружает страницу: точечно обновляется DOM, URL —
через `history.replaceState()`, скролл и фокус на месте. Модули, которые
сами рисуют контент, подписываются на `onLangChange()`. Приоритет источника
языка: `?lang=` → `localStorage` → `ru`.

## Данные и корзина

В `localStorage` под ключом `dala:cart` лежит **только `[{ id, qty }]`**.
Названия и цены сохранять нельзя — корзина застрянет на старом языке и старых
ценах. Всё остальное берётся из `data/menu.js` по id, включая сумму.

Хранилище читается с недоверием: неизвестные id, мусор и дубли отсеиваются
в `readStorage()`, нормализованный вид тут же записывается обратно.
`localStorage` может быть недоступен (приватный режим) — все обращения
в `try/catch`, без него функциональность доживает до перезагрузки.

Состояние меняется только через API `cart.js` (`addItem`, `incrementItem`,
`decrementItem`, `clearCart`); `getItems()` отдаёт копию. Каждое изменение
шлёт `CART_CHANGE_EVENT` с `reason` — по нему UI решает, показать тост
(`add` из меню) или объявить в `aria-live` (действия внутри панели).

Цены форматирует `formatPrice()` — не `Intl`: нужен один и тот же вид
в обеих локалях, с узким неразрывным пробелом.

## Доступность

Модальные панели (корзина, мобильное меню): пока открыты, `header` и `main`
помечаются `inert` — отдельная ловушка фокуса не нужна. Регион тоста
исключён из inert атрибутом `data-modal-keep`, иначе объявление не прозвучит.
При открытии фокус уходит на кнопку закрытия, **при закрытии возвращается
на кнопку-источник**. Esc закрывает.

`aria-live`-регионы существуют в разметке с самого начала: элемент, созданный
на лету или спрятанный через `display:none`, ничего не объявит. Атрибут
`hidden` в base-слое усилен `!important`, чтобы побеждать утилиты `display`.

Кольцо фокуса — `cocoa` 2px с отступом 2px; на тёмной секции (`.on-dark`)
подменяется на `blush`. Минимальная цель для пальца — 44×44.
`prefers-reduced-motion` гасит анимации и `scroll-behavior`.

## Проверка перед завершением работы

- ширины **375 / 768 / 1440** — на каждой;
- переключение на **казахский**: строки длиннее русских, ломают кнопки
  и заголовки первыми;
- обход с клавиатуры: Tab по секции, Esc в открытой панели, возврат фокуса;
- `npm run build` без предупреждений.
