# DALA COFFEE

Статический двуязычный сайт кофейни (Астана). Бэкенда нет: Vite + Tailwind CSS v4,
обычный JavaScript, ES-модули.

## Команды

```bash
npm install
npm run dev      # дев-сервер на http://localhost:5173
npm run build    # прод-сборка в dist/
npm run preview  # локальный просмотр собранного
```

## Структура

```
index.html            разметка страницы
src/styles.css        дизайн-система: токены (@theme), base-слой, утилиты проекта
src/i18n.js           определение языка, t(), applyLang(), событие смены языка
src/main.js           шапка, переключатель языка, мобильное меню
src/data/locale.js    все строки интерфейса (ru / kk)
src/data/menu.js      меню: категории, напитки, formatPrice()
public/images/        фотографии
```

## Куда класть фотографии

Всё, что лежит в `public/`, отдаётся с корня сайта: `public/images/hero.jpg`
доступен как `/images/hero.jpg`.

| Файл | Где используется | Пропорции | Рекомендуемый размер |
| --- | --- | --- | --- |
| `images/hero.jpg` | первый экран, стакан кофе | 4:3 на мобильном, 4:5 на десктопе | 1200×1500 |

Кадрируйте под 4:5 — на широких экранах картинка показывается именно так,
а на узких обрезается по центру через `object-fit: cover`.

Пока файла нет, контейнер остаётся с градиентом `--blush → --milk`:
у `<img>` стоит `onerror`, который прячет битую картинку, и вёрстка не ломается.
Отдельной заглушки в репозитории нет намеренно — так сразу видно, что фото ещё не положили.

Формат: JPEG для фотографий (или WebP, если не нужна поддержка совсем старых браузеров).
Держите вес до ~300 КБ — сайт статический, CDN и оптимизации на лету не будет.

## Локализация

Языки: `ru` (по умолчанию) и `kk`. Приоритет определения — `?lang=` в URL,
затем `localStorage`, затем `ru`.

Тексты в разметку не пишутся, всё идёт через словарь `src/data/locale.js`:

```html
<h1 data-i18n="hero.title">Кофе в центре степи</h1>
<meta name="description" data-i18n-content="meta.description" content="…" />
<button data-i18n-aria-label="a11y.openMenu">…</button>
```

`data-i18n` подменяет текст элемента, `data-i18n-<атрибут>` — соответствующий атрибут.
Текст внутри HTML остаётся русским вариантом: он виден, если JS не загрузился.

Смена языка не перезагружает страницу и не сбрасывает скролл. Модулям, которые
рисуют контент из JS, нужно подписаться на событие:

```js
import { onLangChange, translateTree } from './i18n.js';

onLangChange(() => renderMenu());   // перерисовать свой блок
translateTree(newlyInsertedNode);   // перевести только что вставленную разметку
```

## Дизайн-система

Токены объявлены в `src/styles.css` в блоке `@theme static` и доступны и как
CSS-переменные (`var(--color-caramel)`), и как утилиты Tailwind (`bg-caramel`).

Палитра и шкала кеглей закрыты: дефолтные наборы Tailwind сброшены через
`--color-*: initial` и `--text-*: initial`. Утилит вроде `bg-blue-500` или
`text-6xl` в проекте не существует — случайно вынести цвет за палитру нельзя.

Цвета: `espresso`, `milk`, `caramel`, `cocoa`, `blush`, `stone`, `white`, `alert`.
Правила применения — в комментариях рядом с токенами.

Кегли: `text-caption` 12, `text-small` 14, `text-body` 16, `text-lead` 20,
`text-h3` 28, `text-h2` 40, `text-h1` 64.

Шрифты: Unbounded (заголовки, 600/700) и Inter (текст, 400/500), подключены
с Google Fonts. Оба покрывают кириллицу и казахские ә ғ қ ң ө ұ ү һ і.
